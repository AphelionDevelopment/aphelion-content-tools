Unresolved markers

      
Markers whose module attribution could not be confirmed against a real module
        directory — most existing markers in Meridian-Rift only carry a free-text reason, not a clean
        module id, so this list is expected to be long. Expand a marker to review its Git history and
        associated pull requests, or to correct its label so a future scan attributes it correctly.
