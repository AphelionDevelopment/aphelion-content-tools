Cache and Storage Management

Background jobs that keep the Lore Editor's Catalog and the Content Graph's cache in sync with the game checkout. None of these run automatically — the Catalog, generated DM artifact, and content graph are all snapshots on disk, so re-run the relevant job here after pulling new game-repo changes or hand-editing files outside the app, before trusting what the other pages show. Hover a button below for what it does and when to use it.

Stage a Commit

            

              Writes the generated lore override artifact into this checkout so it's ready to commit. Three
              steps, always in order: generate builds and validates the artifact outside
              the game checkout — it never touches Meridian-Rift and is always safe to run; select
              the prepared stage to apply, defaulting to the most recently generated one; then
              apply writes it into the game checkout and opens GitHub Desktop so you can
              review the diff and commit it.
