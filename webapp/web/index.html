About

Aphelion Content Tools

A growing suite of local tools for working on the Meridian-Rift SS13 fork: reviewing and overriding lore content, exploring how modules connect to the rest of the checkout, and keeping the game repository's Git workflow in one place.

  • File Management — repository status, Git actions, game-repository export, and cache/storage jobs.
  • Lore Editor — review catalog content and maintain lore overrides.
  • Content Graph — visualize modules, master_files overrides, and edit markers.
